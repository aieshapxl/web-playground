# fintrack

a simple personal finance dashboard for managing income, expenses, and account profiles.

## features

* user registration and login
* personalised dashboard
* income and expense tracking
* transaction filtering and search
* income, expense, and balance summaries
* cash-flow chart
* profile and currency settings
* light/dark mode
* localstorage-based data persistence

## tech stack

* html
* css
* javascript
* localstorage
